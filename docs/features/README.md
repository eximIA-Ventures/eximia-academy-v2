# Features

Documentação de produto por feature: o que ela faz, que regra de negócio ela carrega e o que não pode ser quebrado. Complementa os READMEs de código dos workspaces, que explicam *como* está implementado.

| Feature | O que cobre |
|:---|:---|
| [Motor Socrático](./motor-socratico.md) | O tutor que provoca com perguntas e nunca entrega resposta pronta. Diferencial nº 1 do produto. |
| [Course Designer](./course-designer.md) | Pipeline de criação de curso assistida por IA. |
| [Multi-tenant](./multi-tenant.md) | Isolamento por tenant, white-label, hierarquia de acesso e planos. |

Mais features serão documentadas aqui conforme forem fatiadas do README raiz e dos relatórios soltos na raiz do repositório.
